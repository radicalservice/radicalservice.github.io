# Radical Service – service Apple București: MacBook, iPhone, iPad, iMac, Apple Watch

Pagina din acest repo ([radicalservice.github.io](https://radicalservice.github.io/)) este versiunea în engleză, pentru expați și turiști, a site-ului [radicalservice.ro](https://radicalservice.ro/) – atelier independent de reparații Apple din București, Sector 1 (zona Domenii), din 2014. Reparații la nivel de componentă, microsoldering, recuperare date, piese originale sau OEM premium, garanție scrisă până la 12 luni.
